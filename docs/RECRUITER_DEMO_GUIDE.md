# Recruiter / Interview Demo Guide

## 10-minute story
- Problem: claims evidence is multimodal, fragmented and regulated.
- Architecture: Next.js + FastAPI + PostgreSQL/Redis/vector retrieval + OpenAI/LangChain/LangGraph + MCP + SSE.
- AI engineering: hybrid/multi-RAG, grounded citations, specialist agents, durable human interrupts, multimodal evidence fusion, evals and LLMOps.
- Production engineering: tenancy/RBAC, immutable audit, migrations, security red-team gates, DR/SLO gates, GitOps release governance.
- Safety boundary: AI recommends and monitors; humans own claim decisions, regulatory authority, residual-risk acceptance, security/operational certification and production go-live.

## Strong interview proof points
Show a synthetic claim from ingestion through multimodal retrieval, agent investigation, human review and audit provenance. Then show the integrated release-candidate, security, operational-readiness and human go-live gates to demonstrate that the project is more than an API wrapper.
